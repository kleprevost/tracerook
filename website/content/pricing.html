Questions

What do I need?

An Apple Silicon Mac running macOS 26 or later and Claude Code. Installation guide

Do I need an Anthropic API key?

No. TraceRook Cloud is included and runs Claude on TraceRook's account. You connect with the access code you receive when you join.

What is sent to the cloud?

Only a projection of each ambiguous action: categories and signal codes, re-scanned for secrets. Privacy pipeline

Does it work without Cloud?

Yes. Local rules and native review run entirely on your Mac. Cloud adds Claude's contextual judgment.
