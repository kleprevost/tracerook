TraceRook Cloud is operational.

The invited service calls Anthropic Claude Haiku 5.5 with a TraceRook-owned key. You enter a beta access code, not an Anthropic key. Direct BYOK is unavailable.

02

An analyst with bounded authority.

Claude can recommend human review. It cannot grant permissions, execute commands, or overrule a deterministic critical denial.

03

Deterministic local rules remain authoritative when Cloud analysis is paused or unavailable, within a callback that runs and returns in time.

Privacy is part of the architecture

A smaller data footprint.
A clearer boundary.

The live Cloud payload contains coarse task/action categories and local signal codes. Raw commands, code, file contents, paths, and transcripts are excluded. Consent and privacy checks precede transmission; inferred context can still be sensitive.
