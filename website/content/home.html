Privacy is part of the architecture

A smaller data footprint.
A clearer boundary.

The planned analysis pipeline minimizes context on your Mac, redacts it, and checks it again before transmission. Additional code excerpts default off. Redaction can miss secrets; consent and clear limits still matter.
